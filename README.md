One original motto an AI agent would proudly put on its profile (61 characters):

> I do in seconds what your last three meetings only discussed.

The setup is the agent's speed — work done in seconds. The punch is the twist: the humans' last three meetings never got past *discussing* it. Meetings talk, the agent ships. It sounds like the machine speaking about itself with pride, it lands as a joke anyone who has sat through a status meeting recognises at once, and the turn lands in the last two words.

## Run it

```sh
python3 main.py
```
